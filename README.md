This project is designed to run locally in the browser. You can open `index.html` directly or run a simple local web server.

## Run Locally

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Use the included startup script

On Windows:

- Double-click `start-server.bat`
- Or run `start-server.ps1` in PowerShell

Then visit:

```text
http://localhost:8000
```

### Option 3: Use Python manually

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
